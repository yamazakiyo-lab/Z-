## 1. はじめに

### 1-1. TSEG WORKSとは

会社の写真・動画・過去の指令書PDF、工番、納入先、部品在庫を、ブラウザからまとめて検索できる社内アプリです。目的の資料や在庫を、工番・工事名・納入先・部品の型式などから素早く探せます。

ホーム画面から用途別のメニューを選んで使います。メニューは今後も追加されます。

現在のメニューは次の7つです。①FMP SEARCH（写真・動画・指令書PDF検索）／②FM POST（マイフォト: 自分の作業写真・動画の投稿・管理）／③工番検索／④顧客検索／⑤部品在庫検索（寄居・綾瀬の貯蔵品）／⑥動治工具・測定具・消耗品検索／⑦AI Q&A（AIへの質問）。このほか、見積作成メンバーには「💰 QUOTATION SEARCH（過去見積検索）」が表示されます。

### 1-2. アクセス方法

- 会社で配布されているTSEG WORKSのURLをブラウザで開きます(タブレット・スマートフォン・PCどれでも可)。

- 初回アクセス時は、会社の Microsoft アカウント(Entra ID)でサインインします(Googleアカウントは使いません)。

- スマホ・タブレットではブックマークやホーム画面追加をしておくと便利です。

- 社外から使う場合は、会社のネットワーク接続(VPN等)が必要なことがあります。

## 2. ホーム画面とメニュー

最初に開くと「ホーム(玄関ページ)」が表示されます。使いたい検索メニューをクリックして進みます。左側のサイドバー(スマホでは左上の「≫」)からも各メニューに移動できます。

| メニュー | 何を探すか |
| --- | --- |
| 🔍 FMP SEARCH | 写真・動画・過去の指令書PDF |
| 📸 FM POST(マイフォト) | 自分の作業写真・動画を工番別アルバムで管理し、作業完了後にコメント付きで格納 |
| 🔎 工番検索 | 工事名・納入先・工番の一部から「工番」を探す(完成/未成でも絞れる) |
| 🏢 顧客検索 | 顧客(会社名)から、その取引先の工番・写真 |
| 📦 部品在庫検索 | 貯蔵品(寄居・綾瀬)の在庫を型式・品名・メーカー等から探す |
| 🛠️ 動治工具・測定具・消耗品検索 | 寄居・綾瀬の工具・測定具・消耗品を品名・型式から探す |
| 💬 AI Q&A | 技術・業務・人事総務の質問にAIが回答(工番実績・社内規程も参照) |
| 💰 QUOTATION SEARCH | 過去見積(2013〜)を顧客名・件名・型式・工番から検索(見積作成メンバーのみ表示) |

## 3. FMP SEARCH（写真・動画・指令書PDF検索）

### 3-1. 検索のしかた

1. 「キーワード」に、工番・作業・コメントなどを入力します(スペース区切りで複数語のAND検索)。

2. 必要に応じて「納入先名」「請求先名」でも絞り込めます(部分一致)。

3. 「🔍 検索」を押すと結果が一覧表示されます。

### 3-2. 絞り込みフィルタ

- 種別: 📷写真 / 🎬動画 / 📄指令書PDF(未選択ならすべて表示)

- フェーズ: 🟦B1 着手前 / 🟩B2 着手中 / 🟨B3 出荷以降 / 🟥B4 整理前 / 🏁F 完成時

- 表示件数: 一覧に出す最大件数を調整できます。

### 3-3. 写真・動画・PDFの見かた

- 写真: サムネイルが表示され、「🔍 拡大」でフルサイズ表示できます。

- 動画: 「🎬 動画を開く / ダウンロード」から別タブ表示またはダウンロードで再生できます(ブラウザで直接再生できない形式でも、ダウンロードすればPCの動画プレーヤーで見られます)。

- 指令書PDF: 「📄 PDFを開く」で別タブに表示されます。

各結果には、工番・工事名・納入先・請求先・撮影日・メモ、元ファイルの保存パスも表示されます。

## 4. FM POST（マイフォト）

自分の作業写真・動画を、工番別のアルバムとして貯めておける「自分専用の置き場」です。作業中の参照や記録に自由に使え、作業が終わったらコメントを付けて「格納」すると、会社の工番フォルダに取り込まれてFMP SEARCHで検索できるようになります。

### 4-1. 使いかた

1. 工番を入力します(工事名が自動表示されるので間違いに気づけます)。

2. 写真・動画を選んで「マイフォトに追加」。動画は30秒までです(mp4/mov)。

3. アルバムは工番ごとに並びます。格納するまでは自分(と管理者)だけが見られ、削除も自由です。

4. 作業が終わったら、アルバムを開いてコメント(作業内容・気づいたこと)とフェーズ(B1着手前/B2着手中/B3出荷以降/F完成時)を選んで「格納する」を押します。夜間の自動処理で工番フォルダに入り、翌日から検索に出ます。

### 4-2. LINE WORKS Botとの使い分け

- LINE WORKS Bot(TSEGFMBot): スマホからその場で投稿(即格納)。従来どおり。

- FM POST: 貯めてから格納。PCからのまとめ投稿にも便利です。

※ 格納しないまま数日たったアルバムがあると、夕方のBotが「未格納のアルバムがあります」とお知らせします(急かすものではありません)。

## 5. 工番検索

「工番が分からないが、工事名や納入先は分かる」ときに、工番を探すためのメニューです。

### 5-1. 検索のしかた

1. 「キーワード」に、工事名・納入先・工番の一部を入力します(例: トータス / 高千穂 / 4031)。

2. 該当する工番が一覧表示されます(工番・工事名・納入先・写真枚数)。

※ 機械名は工事名に含まれることが多いため、機械名でも工事名検索でヒットします。

※ 一覧に出るのは「写真がある工番」だけです。そのため、見つけた工番で写真を見れば必ず表示されます。

### 5-2. 完成 / 未成で絞り込む

- 「状態で絞り込み: すべて / 完成 / 未成」で、案件の状態で絞れます。

- 各工番には 🟢完成 / 🔴未成 のバッジが付きます(工事完成日の有無で判定)。

### 5-3. 写真へジャンプ

- 一覧の「📷 写真を見る」を押すと、FMP SEARCH に切り替わり、その工番の写真が自動表示されます。

## 6. 顧客検索

納入先(注文者)の会社名から、その取引先の工番・写真をまとめて探すメニューです。

1. 「納入先名」に会社名の一部を入力します(例: 高千穂 / 須藤)。

2. 該当する納入先が一覧表示されます(工番数・写真件数つき)。

3. 納入先を開く(展開する)と、その取引先の工番・工事名・写真枚数が並びます。

4. 「📷 写真を見る」で、その工番の写真へジャンプできます。

## 7. 部品在庫検索

貯蔵品(寄居・綾瀬)の在庫を、型式・品名・メーカー・仕入先・棚番から探すメニューです。

### 7-1. 検索のしかた

1. 「キーワード」に、型式・品名・メーカー・仕入先・棚番のいずれかの一部を入力します(例: ベアリング / SMC / 6203 / TN1)。

2. 必要なら「カテゴリで絞り込み」で、在庫カテゴリを選べます。

3. 該当する部品が表で表示されます。

### 7-2. 表示される項目

- カテゴリ / 棚番 / 型式・品名 / 用途・仕様 / メーカー / 数量 / 見積単価

※ 画面上部に「在庫データ更新日」と「登録品目数」が表示されます。在庫表の更新後に反映されます。

## 8. 動治工具・測定具・消耗品検索

寄居・綾瀬の動治工具・測定具・消耗品を、品名・型式・仕様・メーカーから探すメニューです。

1. 「キーワード」に品名・型式・仕様・メーカーのいずれかの一部を入力します(例: トルクレンチ / ミツトヨ / T4MN300)。

2. 「拠点で絞り込み」で 寄居 / 綾瀬 を選べます。

3. 「カテゴリで絞り込み」でメカ動治工具・測定具・電気などの分類で絞れます。

4. 表示項目: 拠点 / カテゴリ / 品名 / 型式 / 仕様・用途 / メーカー / 個数 / 単位

※ 元データは寄居・綾瀬の工具リスト(Excel)です。毎晩自動で最新化されます。

## 9. AI Q&A（AIへの質問）

技術・業務・人事総務の質問を入力すると、AI(GPT-4o)が日本語で回答するメニューです。LINEのようなチャット形式で使えます。

### 9-1. 使いかた

1. 画面下の入力欄に質問を入力して送信します(例: ステンレスの溶接で気をつけることは？ / 有給休暇の申請はいつまで？ / 出張の日当はいくら？)。

2. 数秒でAIの回答が表示されます。続けて質問すると、前のやり取りを踏まえて答えます。

3. 質問が社内の工番実績に関係する場合、AIは社内データを検索して回答に反映します。参照した工番は「参照した社内データ」として回答の下に表示されます。

4. 人事・総務の質問には、社内規程(就業規則・給与規程・出張旅費規程など)を検索し、規程名・条番号付きで回答します(📖マークで表示)。規程に該当箇所が見つからない場合は、推測せず人事課への確認を案内します。

5. このアプリの使い方の質問(「写真はどうやって投稿するの？」など)には、この利用マニュアルを根拠に章名付きで答えます(📘マークで表示)。

6. 在庫の質問(「○○の在庫ある？」「ノギス何本ある？」)には、部品在庫・動治工具のデータから数量を直接答えます(昨晩時点。最新は部品在庫検索・動治工具検索メニューで確認してください)。

7. 予定の質問(「今日の出張は？」「明日○○さんいる？」「9月の工事予定は？」「今月の私の休みは？」)には、LINE WORKSカレンダーの予定(半年先まで)を根拠に答えます。年次点検などの繰り返し予定にも対応しています。

8. 会社の経営方針・重点施策の質問(「うちの重点施策は？」など)には、中期経営計画書を根拠に章名付きで答えます(📋マークで表示)。

9. 過去見積・建値表(標準工数・価格)の質問には、見積作成メンバーに限り過去の見積書・建値表を根拠に答えます(それ以外の方には回答されません)。

### 9-2. 注意

- やり取りは記録されます(誰が・いつ・何を質問したか)。業務目的で利用してください。

- AIの回答は参考情報です。重要な判断(安全・品質・契約に関わることなど)は、必ず関係者・資料で確認してください。

- 社内データの検索対象は、写真のコメントや工番情報などです。データが少ない工番については答えられないことがあります。

## 10. QUOTATION SEARCH（過去見積検索）

過去の見積書(2013年〜、旧xls・PDF含む約6,100ファイル)を検索できるメニューです。見積の検索、過去見積の検索、以前いくらで出したかの確認はこのメニューを使います。※表示されるのは見積作成メンバーのみです。

1. 「検索キーワード」に件名・型式・明細の品名・工番などを入力します(例: ツメ / QD1 / NC1-110 / オーバーホール)。

2. 「顧客で絞る」に顧客名の一部を入れると、その顧客の見積だけに絞れます(例: リアライズ)。

3. 表示順は「関連度順(おすすめ)」と「日付の新しい順」を切り替えられます。

4. 下の「見積のプレビュー」で展開すると、見積の中身(明細)がそのまま読めます。実ファイルを開くときは、表示されたパスをコピーしてエクスプローラーのアドレス欄に貼り付けてください。

※ 1つのExcelにシートを積み上げた見積台帳も、シート単位(1シート=1見積)で検索・プレビューできます。金額は自動抽出値のため、正確な内容は必ずファイル本体で確認してください。

※ AI Q&Aでも見積メンバーであれば「○○社のNC1-110整備、過去いくらで出してる？」のように質問できます。

## 11. 工番の振り返り（LINE WORKS Bot）

工事が終わった工番について、LINE WORKSのTSEGFMBotから「振り返り依頼」が届くことがあります。次回の見積・段取りに活かすための仕組みです。

1. Botから「📋 工番 ○○○○-00 の振り返り依頼です」というメッセージが届きます。

2. 「残しておきたい課題、実際の失敗や客先クレームがあれば記入してください」に、そのまま返信1回で回答します(自由記述。無ければ「なし」、答えられない場合は「X」で中止)。

3. 回答は記録され、今後の見積精度の改善に使われます。個人の評価には使いません。

※ 依頼の発信は見積作成メンバーが行います(Botに「R工番」(例: R4671-00)と送ると宛先を聞かれます。「R4671-00 阿部 飯島」のように名前を続けると直接送信)。

## 12. 使い方のヒント・注意

- スマートフォンでは、表(部品在庫など)が画面幅で切れることがあります。表を横にスクロールすると数量・見積単価まで見られます。

- うまく出ないときは、キーワードを短く・部分的にすると見つかりやすくなります。

- 工番検索・顧客検索は「写真がある工番」を対象に集計しています。写真がまだ無い新しい工番は出ないことがあります。

- 在庫・工番の状態(完成/未成)などのデータは、元データの更新後に反映されます。すぐ反映されない場合は時間をおいて再読み込みしてください。
